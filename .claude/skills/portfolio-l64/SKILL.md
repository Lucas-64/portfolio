# Portfólio L64

Regras fixas para trabalhar neste repositório. Em caso de dúvida, pergunte ao Lucas em vez de supor.

## Stack
- Next.js (App Router) + React + TypeScript.
- O site atual (HTML, CSS e JS puros na raiz) é a referência da migração.

## Preservação
- Preservar o design, o conteúdo e as funcionalidades do site atual.
- Mudanças visuais ou de conteúdo além da migração só com pedido explícito do Lucas.

## Nunca inventar
- Não inventar tecnologias, métricas, experiências, empresas ou funcionalidades que o Lucas não tenha confirmado.
- Se faltar informação, perguntar antes de escrever. Não usar texto placeholder inventado (lorem ipsum plausível, números, depoimentos).

## Domínio
- O domínio final continua sendo https://l64.net.br (usar em canonical, Open Graph, sitemap e metadataBase).

## Projetos novos
- Ao adicionar projetos, usar somente os dados fornecidos pelo Lucas: nome, stack, link e descrição.
- Campo não fornecido fica de fora (ou pergunte); não complete por dedução.

## Validação visual
- Após cada mudança visual, validar com a skill `webapp-testing`: screenshot e checagem de erros no console (desktop e mobile).
- Relatar o resultado, incluindo erros encontrados.

## Skills relacionadas
- `frontend-design`, `webapp-testing`, `skill-creator` (Anthropic).
- `vercel-react-best-practices`, `web-design-guidelines` (Vercel).
